# Listing Image Skill

Install with the official skills CLI:

```sh
npx skills add leodknuth/listing-image-skill --skill listing-image
```

Use `-a claude-code` or `-a codex` to select an agent, and add `-g` for a user-level installation. See the [installation guide](INSTALLATION.md). The source is a private GitHub repository, so your account must have access.
